## Overview

Obsidian Spaced Repetition brings proven spaced repetition algorithms directly into Obsidian, turning your notes into flashcards for effective long-term memorization.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Obsidian Spaced Repetition** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Flashcard Creation** | Convert any note heading or inline block into a review card |
| **SRS Algorithm** | FSRS and SM-2 algorithms schedule reviews for optimal retention |
| **Progress Tracking** | Detailed stats on retention rate and due cards per deck |
| **Markdown Native** | Cards live in plain Markdown files alongside your notes |
